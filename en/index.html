Questions

Do I need the game disc?

Does the executable run without the ISO?

No. Today it is a native port by static recompilation: the game’s code was translated from PlayStation MIPS into native code and runs without an emulator, but the data still comes from your disc — SLUS_010.68 itself (the executable’s tables, text and data) and every asset: tracks, cars, textures, videos, music and menus.

Without the NASCAR Rumble (USA) .cue/.bin the port does not start. It is the same model as other recompiled ports: bring your own copy.

So is it a real native port?

Yes in how it runs: there is no CPU emulator and no BIOS; the game is a native macOS ARM program that reimplements the PS1 hardware (GPU, audio, CD, video) in its own layer.

Not in the sense of an independent source port: the code is still a direct translation of the original executable, not rewritten source. Decompilation and understanding the code continue in parallel.

Will I be able to download and play it?

The plan is to ship only our code and tools, for use with your legal copy. Before that: 2 players and the Mac, Windows and Linux packages.

Does the championship work?

Yes. The Gold Rush cup runs end to end in the port: driver name, three rounds, points, overall standings and the original unlocks (Pro class, new locales and bonus tracks). And that progress now saves to the memory card.
