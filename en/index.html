The game

NASCAR Rumble, EA’s arcade classic

Released by EA in 2000 for PlayStation and Nintendo 64, NASCAR Rumble took stock-car racing and threw realism out the window: power-ups, wild shortcuts, storms and a garage of absurd unlockable cars. A kart racer dressed as NASCAR — pure weekend chaos.

🏁 Fun fact: digging through the game code we already found hidden car names like Golf Cart, Jet Car and EA Sports Car.

What is this project

Work fronts

A long-term effort to run the original NASCAR Rumble as a native app. Reverse engineering and decompilation support that foundation; enhancements and mods will follow playable parity.

🏁

Original game first

Intro, menu, and a complete race before enabling any modification.

💻

Native port

Apps for macOS, Windows, and Linux using the player’s legal copy.

🔧

Enhancements later

Resolution, graphics, and mods will follow on a validated original base.
