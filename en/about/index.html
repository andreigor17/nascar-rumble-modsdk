About & Contribute

This is an independent reverse-engineering and documentation project for NASCAR Rumble (PlayStation 1). The current goal is to run the original game as a native app while preserving its behavior. Graphics enhancements and a modding SDK will follow that playable, stable foundation.

How to contribute

  • Code and docs on the GitHub repository.
  • Suggestions and findings can become issues.
  • Every discovery is logged in Progress with evidence and is reproducible.

Disclaimer

Fan project, not affiliated with Electronic Arts. No game files are distributed; screenshots are shown only to document progress. The tools operate on a copy of the game you must legally own. Part of this work is AI-assisted under human review.
